# Sistema de Cadastro em Python

## Sobre o projeto

Este projeto é um sistema de cadastro desenvolvido em Python.
Ele permite cadastrar, listar, buscar, atualizar e excluir usuários,
com os dados armazenados em um arquivo JSON.

## Funcionalidades

- Cadastrar usuário
- Listar usuários
- Buscar usuário
- Atualizar usuário
- Excluir usuário
- Salvar dados em JSON
- Carregar dados ao iniciar o programa
- Validar dados digitados
- Tratar erros de entrada

## Tecnologias utilizadas

- Python
- JSON
- Git
- GitHub
